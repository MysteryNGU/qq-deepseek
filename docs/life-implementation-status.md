## 2. 设置网页使用与限制

1. 启动项目 supervisor 后打开 <http://127.0.0.1:6100/>；首次本机密码在 `data/settings/login.txt`。密码和真实配置不进入 Git。
2. 修改后点击“保存修改”。复杂字段可展开完整 JSON；格式或范围错误不覆盖文件，切换页面后仍检查未完成草稿。
3. 点击“重启并生效”。已有工作结束后加载；离线时旧进程遗留的轮次不能永久阻挡重启。宿主在线、QQ 连接、认知服务就绪分别展示。
4. 配置被其他程序修改时返回冲突，须重新载入合并；环境变量覆盖项单列。多个文件分别原子保存，部分失败时已保存项和失败草稿分别保留。

浏览器实际验证：登录、错误 JSON 跨页面阻止保存、已有小数超时参数兼容、历史画像开关保存、待生效提示、重启回执、运行配置哈希一致。网页独立于 QQ 登录运行。当前不增加多人账号管理、可视化角色卡编辑或任意命令执行入口。

## 3. 连续活动与画像的约束

- 连续行为依附明确事项。单次请求、未绑定兴趣不会自动变成无限续行；自发活动有步数上限，连续无进展暂停。
- 进展来自新的确认送达片段或成功操作，重复文本和未确认发送不算进展。用户停止、等待答复、未知操作结果及来源失效阻止继续；经过一段时间不代表用户回答了问题。
- 群聊转私聊仍核对真实发言人、来源可读性和最新已读请求，不复制成两个同时执行的任务。
- 历史画像是独立内部批次，不向 QQ 发消息，不恢复旧摘要批次。每条来源形成有证据画像或“无新增”复核；未知受理核对原调用，暂停批次不重新付费循环提交。
- 画像保留来源、主题、修订及有效期；旧材料不能覆盖更新的本人陈述，推测不能伪装成本人事实。没有可靠信息的人可以有身份档案而没有偏好条目。
