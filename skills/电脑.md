# 在电脑上处理事情

先查看当前 DSH 的真实工具目录，再选择文件、命令、浏览器或桌面操作能力。旧 `computer action=...` 和 `device action=...` 接口已经退出生产，不要把这份经验当作仍存在的工具目录。

这台机器使用 Windows。执行 PowerShell 或明确的 Python/Node 程序；先观察窗口或文件，再操作并核对结果。界面坐标会过期，点击前重新截图或读取控件。图像生成可使用已安装的 Pillow；中文字体可用 `C:/Windows/Fonts/msyh.ttc`。

生成图片后核实文件内容，通过 `life_read` 的媒体 import 动作注册为当前会话资产，再用 `life_say` 图片片段发送。所有 QQ 正文与媒体走统一发送入口，不能用界面自动化另发一份。输出文件存在、上传完成和对方实际收到是不同结果。

长操作可委派子代理，但主角色要保留原目标并可随时处理插话。缺少桌面工具时，通过当前工具和插件目录寻找真实可执行的方法，明确记录尚未具备的能力，不虚构界面操作成功。
