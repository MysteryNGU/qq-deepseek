# 方法文件的格式（给自己看的说明）

一份方法 = 一段 YAML 头 + 两节正文。

```markdown
---
name: 一句话名字
when: 什么情况下该用它（检索靠它）
preconditions: 用之前要满足什么
checkpoints: 怎么算做成了（能看见的证据）
success: 0
fail: 0
last_verified: 0
version: 1
author: self        # self=你自己写的，owner=主人写的
status: draft       # draft | active | retired
---
## 步骤
1. see
2. tap 动态
3. type 正文
4. verify 正文

## 失败过
- 踩过的坑，一条一句
```

规矩：
- 步骤只能用原语开头：see / tap / type / swipe / key / launch / wait / ask / verify / shell / open / click / read / search / dsh
- 每一步都要能验证；写不出验证点的步骤不要写
- 只成功过一次的方法先留在 draft；第二次也成了再 verify 成 active
- 连续失败三次就 retire，重新学
